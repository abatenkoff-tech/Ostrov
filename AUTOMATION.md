# Автоматическое обновление сайта из ChatGPT

## Рекомендуемая схема
ChatGPT → GitHub → хостинг (Vercel или Netlify) → публичная ссылка.

1. Исходники этого каталога хранятся в отдельном GitHub-репозитории.
2. Хостинг один раз подключается к этому репозиторию.
3. Любой push в основную ветку автоматически публикует новую версию сайта.
4. Для обычных обновлений проекта ChatGPT меняет прежде всего `data/project-data.js`, добавляет новые файлы в `assets/` и `docs/`, затем публикует изменения в GitHub.
5. Хостинг получает commit автоматически; ручная загрузка ZIP больше не нужна.

## Что обновляется из чата
- помещения и площади;
- визуализации;
- ссылки на листы дизайн-проекта;
- инженерные PDF и превью;
- после подключения MASTER — комплектация, цены, статусы и итоги.

## Почему данные вынесены отдельно
`data/project-data.js` — единый контентный слой. Это снижает риск случайно сломать верстку при каждом обновлении и позволяет многократно использовать один шаблон для новых клиентов.

## Безопасность
Текущий код доступа в интерфейсе не является серверной авторизацией. Перед передачей клиенту конфиденциальных документов включите серверный access control / authentication на выбранной платформе.
