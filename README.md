# Клиентский кабинет — ЖК «Остров» — публикационная версия 1.1

## Готово
- адаптивный интерфейс для телефона, планшета и компьютера;
- мобильная нижняя навигация и отдельная desktop-навигация;
- safe-area для iPhone/iPad;
- 8 помещений по актуальному дизайн-проекту;
- отдельные PDF-пакеты по помещениям;
- отопление, ВК, ЭОМ, ОВиК и полные исходные документы;
- `data/project-data.js` как отдельный контентный слой для будущих автообновлений;
- конфигурации одновременно для Netlify и Vercel;
- запрет индексации и базовые security headers.

## Публикация
### Netlify
Можно перетащить этот каталог целиком в Deploy manually. Для автоматизации лучше один раз связать сайт с GitHub-репозиторием — дальше каждый push публикуется автоматически.

### Vercel
Каталог уже содержит `vercel.json` и готов к статическому деплою. При связи проекта с GitHub каждый commit публикуется автоматически.
